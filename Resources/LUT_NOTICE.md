# Film LUT pack

This pack contains display-ready derivatives of LUTs exported from the open-source **spektrafilm** project by Andrea Volpato (https://github.com/andreavolpato/spektrafilm), via the Alcedo LUT export.

- Film simulation: spektrafilm (GPLv3 reference implementation; LUTs/profile data CC BY-SA 4.0).
- ACES 2.0 SDR Rec.709 output transform: Academy Color Encoding System / OpenColorIO 2.6 builtins.
- Combined LUTs are shared under CC BY-SA 4.0. Commercial use of the spektrafilm LUT data is permitted; resale of the LUT pack alone is not.

Regenerate with `Tools/build_luts.py`.
